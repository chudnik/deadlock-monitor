# Deadlock Monitor
Программный комплекс на C++ для многопоточной симуляции распределения ресурсов на основе **Алгоритма Банкира Эдсгера Дейкстры**. Система динамически распределяет разделяемые ресурсы между конкурирующими потоками-воркерами, полностью исключая возможность возникновения взаимных блокировок (deadlocks) на этапе планирования.

## 🚀 Задача и принцип работы
Основная задача: реализовать потокобезопасный монитор ресурсов, который анализирует запросы процессов, проверяет систему на безопасность (безопасное состояние — *Safe State*) и превентивно предотвращает возникновение тупиковых ситуаций.
1. Запрос ресурсов (`request`): Поток запрашивает случайное количество ресурсов. Монитор временно «выделяет» их в уме и запускает проверку безопасности. Если состояние системы остается безопасным, запрос одобряется. Если есть малейший риск взаимной блокировки — поток усыпляется на условной переменной (`std::condition_variable`).
2. Освобождение ресурсов (`release`): По завершении работы поток возвращает ресурсы монитору, что вызывает пробуждение и повторную проверку ожидающих потоков.
3. Логирование: Для минимизации задержек и исключения взаимных блокировок при выводе в консоль, логирование вынесено в выделенный асинхронный поток-воркер с собственной неблокирующей очередью задач.

## 🛠️ Архитектура и технологии
- С++20
- `std::mutex`, `std::unique_lock`, `std::lock_guard` для контроля гонок данных (*Data Races*).
- `std::condition_variable` для эффективного ожидания без использования активного опроса (*busy waiting*).
- `Singleton` паттерн для логгера, обеспечивающий глобальную точку доступа и потокобезопасность.

## 💻 Сборка и компиляция

Для сборки проекта вам понадобятся компилятор с поддержкой C++20 (GCC, Clang) и утилита CMake (версии 3.16+).

```bash
# 1. Клонируйте репозиторий или перейдите в корень проекта
cd path/to/project

# 2. Создайте директорию для сборки и перейдите в нее
mkdir build && cd build

# 3. Сгенерируйте файлы сборки
cmake ..

# 4. Скомпилируйте проект
cmake --build .
```
